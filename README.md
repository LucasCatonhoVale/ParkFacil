# 🚗 ParkFácil

O **ParkFácil** é uma aplicação web desenvolvida com o objetivo de facilitar a busca, o agendamento e o gerenciamento de vagas de estacionamento, proporcionando mais praticidade, organização e eficiência tanto para os clientes quanto para os administradores dos estacionamentos.

A plataforma permite que os usuários consultem estacionamentos disponíveis, visualizem informações sobre localização, horários de funcionamento e avaliações, além de realizarem reservas de vagas de maneira simples e intuitiva.

O sistema também conta com funcionalidades de gerenciamento de reservas, histórico, cadastro e edição de veículos e gerenciamento de estacionamentos, atendendo às necessidades de clientes, funcionários e administradores.

### ⚙️ Funcionalidades
- Cadastro e autenticação de usuários.
- Consulta de estacionamentos disponíveis.
- Visualização de informações e avaliações.
- Agendamento e gerenciamento de reservas.
- Histórico de reservas.
- Cadastro e edição de veículos.
- Gerenciamento de estacionamentos.
- Controle de usuários e funcionários.

### 🛠️ Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript
- Java
- Spring Boot
- MySQL

### 🎯 Objetivo do projeto
Desenvolver uma solução tecnológica que simplifique o processo de encontrar e reservar vagas de estacionamento, melhorando a experiência dos usuários e facilitando a administração dos estabelecimentos.

**ParkFácil — Estacione com praticidade, segurança e facilidade!**
